# Зона контакта — Multiplayer LAN

## Первый запуск на Windows

1. Скачайте ZIP и сохраните его на диск.
2. До распаковки нажмите ZIP правой кнопкой → Свойства. Если внизу есть флажок «Разблокировать», включите его и нажмите Применить. Это стандартная метка Windows для скачанных файлов; отключать Защитник или общую защиту не нужно.
3. Распакуйте архив полностью в обычную папку, например `C:\Games\ZonaKontaktaLAN`. Не запускайте файлы внутри ZIP.
4. Установите Node.js LTS с https://nodejs.org/ (если ещё не установлен). Закройте и снова откройте Проводник после установки.
5. Дважды нажмите `ЗАПУСТИТЬ_ИГРУ.bat`. При первом запуске установятся пакеты; затем сервер откроется в отдельном окне, а игра — в браузере.

## Подключение друзей по локальной сети

В окне сервера будут показаны адреса вида `http://192.168.1.15:3000`. На втором ПК, подключённом к той же сети Wi-Fi/LAN, откройте этот адрес в браузере. Используйте адрес с IP хоста, не `localhost`. Хост не должен закрывать окно сервера.

Если Windows Firewall спросит разрешение, разрешите Node.js для частных сетей. Если порт 3000 занят, закройте другое приложение на этом порту или сообщите об ошибке.

## Запуск только сервера

Дважды нажмите `ЗАПУСТИТЬ_СЕРВЕР.bat`.

## Примечание

Это LAN-прототип. Полный сетевой матч на двух физических компьютерах нужно проверить в вашей сети.


Spawn points: connected players receive different map waypoint indices, so they start at separate locations instead of stacking at the solo spawn.
