# Зона контакта — мультиплеерный сервер

Сервер без зависимостей (только Node.js ≥ 18). Он же раздаёт саму игру (`public/index.html`),
поэтому достаточно открыть адрес сервера в браузере.

## Запуск на Render (бесплатный тариф)
1. Создайте репозиторий на GitHub и залейте в корень содержимое этой папки:
   `server.js`, `sim.js`, `package.json`, `render.yaml`, папку `public/`.
2. Render → **New → Blueprint** (подхватит `render.yaml`) или **New → Web Service**:
   Runtime **Node**, Build Command `echo ok`, Start Command `node server.js`, Health Check Path `/healthz`.
3. Дождитесь деплоя. Адрес будет вида `https://zona-kontakta.onrender.com`.
4. Откройте этот адрес в браузере → в меню блок **«Мультиплеер»** → введите позывной и адрес
   (`zona-kontakta.onrender.com`, без https://) → **Подключиться**.

Бесплатный сервис Render засыпает после ~15 минут без трафика; первое подключение может занять до минуты —
клиент сам повторяет попытки. Игру лучше открывать с адреса сервера (а не из стороннего iframe/страницы),
так WebSocket гарантированно разрешён.

## Режимы (переменная `ROTATION`, через запятую)
`tdm` — командный бой, `ffa` — каждый за себя, `elim` — раунды без возрождения,
`koth` — удержание точки, `coop` — волны ботов против игроков. Режимы меняются по кругу после каждого матча.

## Переменные окружения
| Переменная | По умолчанию | Смысл |
|---|---|---|
| `PORT` | 8080 | Render задаёт сам |
| `ROTATION` | tdm,koth,elim,ffa,coop | порядок режимов |
| `TARGET` | 10 | цель матча (убийства/раунды), 2–20 |
| `DIFF` | 1 | сложность ботов 0–3 (боты заполняют пустые места) |
| `ARMOR` | 3 | класс брони (0/3/5) |
| `MAX_PLAYERS` | 12 | лимит игроков (1–16) |
| `MAP` | poly | карта: `poly` (Полигон) или `dorms` (Общага) |
| `SNAP_HZ` | 20 | частота снапшотов, 10–30 |
| `DEV` | — | отладочные режимы |

## Как устроено
Клиент сам считает своё движение (поэтому нет задержки управления), сервер считает урон, гранаты, ближний бой и режимы.
Выстрелы проверяются с компенсацией задержки (положение целей «отматывается» на пинг стрелка, не более 0,3 с).
Чужие игроки приходят снапшотами и интерполируются (~0,11 с). Боты и люди в бою ничем не отличаются.
Собственная голова не рисуется, чужие головы видны.

## Управление в сетевой игре
`Z` — таблица игроков (удерживать), `Enter` — чат. Остальное как в обычной игре.

## Проверка
`GET /healthz` отвечает `ok`. Локально: `PORT=8080 node server.js`, затем http://localhost:8080/.
